🍔 Food Ordering Web Application
📌 Project Overview

This is a simple Food Ordering Web Application built using HTML, Python (Flask/Server), and SQLite database.
The application allows users to browse food items, view images, and place orders, while admins can manage the system.

🚀 Features
🍕 View food menu with images
🛒 Order food items
🗂️ Backend server using Python
💾 Data stored in SQLite database
🔐 Admin panel for management
📱 Simple and responsive UI

🛠️ Tech Stack
Frontend: HTML, CSS
Backend: Python (server.py)
Database: SQLite (database.sqlite)
📂 Project Structure
project/
