🐘 Connecting pgAdmin4 to Foodz Database

Follow these steps to view and manage all database tables inside your local pgAdmin4 app:

  1. Open pgAdmin4 application on your computer.
  2. Right-click on Servers → Register → Server...
  3. In the General tab, name it: Foodz Swiggy Postgres
  4. In the Connection tab, enter:
    • Host name/address: localhost
    • Port: 5432
    • Maintenance database: postgres or foodz_db
    • Username: postgres
    • Password: password (or your local Postgres password)
  5. Click Save and expand Databases → foodz_db → Schemas → public → Tables.
  6. You will see all tables: users, restaurants, categories, menu_items, orders, reviews!
  7. To run custom queries, right-click foodz_db and open Query Tool. Open and execute swiggy_schema.sql and swiggy_seed.sql!
